# Cluster训练 (Cluster Training / Intraset Rest Training)

Cluster训练（间休训练）将传统多重复组划分为多个微组，微组间插入短暂休息(5-30秒)，用于维持高强度运动单位募集。

## 核心概念

- **微组 (Micro-set)**: 2-5次的小组
- **短暂休息**: 5-30秒，允许代谢产物部分清除
- **维持输出**: 延缓II型纤维脱逸，保持动作速度

## 训练方法分类

| 方法 | 微组大小 | 休息时间 | 主要目标 |
|------|---------|---------|---------|
| Cluster Set | 3-5次 | 10-30秒 | 维持强度 |
| Rest-Pause | 3-5次(初始) | 15-20秒 | 延长力竭距离 |
| Intraset Rest | 1-3次 | 5-15秒 | 保持速度 |
| Contrast | 2-4次 | 10-20秒 | 转化力量至爆发力 |

## 训练效果

| 指标 | 提升幅度 | 证据等级 |
|------|---------|---------|
| 爆发力输出 | +5-15% | A级 |
| 垂直跳 | +5-12% | A级 |
| 1RM深蹲 | +8-12% | B级 |
| 肌肉肥大 | 与传统组相当 | B级 |

## 实践参数

| 参数 | 推荐值 |
|------|-------|
| 总重复次数 | 8-12次 |
| 微组大小 | 3-5次 |
| 微组间休息 | 10-30秒 |
| 组间休息 | 2-4分钟 |

## 适用动作

- **优先**: 奥林匹克举重、深蹲、硬拉
- **中等**: 卧推、肩推、划船
- **不推荐**: 小肌群孤立动作
