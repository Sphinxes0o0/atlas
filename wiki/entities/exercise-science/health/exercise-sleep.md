# 运动与睡眠质量 (Exercise & Sleep Quality)

## 定义

规律运动是改善睡眠质量的有效非药物干预手段。运动通过体温调节、能量消耗、压力和焦虑减轻等多重机制促进更好的睡眠。

## 运动对睡眠的影响

| 睡眠参数 | 运动效果 | 证据强度 |
|---------|---------|---------|
| 入睡潜伏期 | ↓ 减少 | 强 |
| 总睡眠时间 | ↑ 增加（~10-15分钟） | 中等 |
| 深睡眠（慢波睡眠） | ↑ 增加 | 中等 |
| 睡眠效率 | ↑ 提高 | 强 |
| 觉醒次数 | ↓ 减少 | 中等 |
| 主观睡眠质量 | ↑ 改善 | 强 |

## 作用机制

| 机制 | 描述 |
|------|------|
| 体温调节 | 运动后体温升高→后续降温促进睡眠启动 |
| 能量消耗假说 | 身体活动增加睡眠需求 |
| 焦虑减轻 | 运动降低焦虑，减少睡前思维激活 |
| 昼夜节律调节 | 光照+运动强化节律信号 |
| 腺苷积累 | 运动增加大脑腺苷→促进睡眠压力 |

## 运动处方

| 参数 | 建议 |
|------|------|
| 运动类型 | 有氧运动最优，阻力训练也有益 |
| 强度 | 中等强度（60-75% HRmax）最有效 |
| 时长 | 30-60分钟/次 |
| 频率 | 3-5次/周 |
| 时机 | 睡前4-6小时完成运动（避免睡前2小时内中高强度运动） |

## 运动时机的考虑

| 时间 | 效果 |
|------|------|
| 早晨 | 强化昼夜节律，不影响夜间睡眠 |
| 下午（最佳） | 核心体温峰值附近，运动表现好，睡眠改善最明显 |
| 傍晚 | 对大部分人无害，部分人可能过度兴奋 |
| 睡前2小时内 | 敏感人群可能入睡困难（个体差异大） |

## 特殊人群

- **老年人**：运动改善睡眠的效应更强（年龄相关睡眠质量下降更明显）
- **失眠症**：中等强度有氧可作为失眠的辅助治疗
- **运动员**：高强度训练可能暂时影响睡眠，需合理安排
