# 衰老、肌少症与运动 (Aging, Sarcopenia & Exercise)

## 定义

肌少症（Sarcopenia）是与年龄相关的骨骼肌质量、力量和功能进行性下降。30岁后肌肉量约每十年下降3-8%，60岁后加速。运动是延缓甚至逆转肌少症的最有效策略。

## 衰老相关的肌肉变化

| 变化 | 表现 | 后果 |
|------|------|------|
| II型肌纤维萎缩 | 快缩纤维优先丧失 | 力量和爆发力下降 |
| 运动单位减少 | 神经支配减少 | 精细运动控制下降 |
| 线粒体功能下降 | ATP生成效率降低 | 耐力下降 |
| 卫星细胞减少 | 再生能力受损 | 损伤后恢复慢 |
| 合成代谢抵抗 | MPS对蛋白质/训练反应迟钝 | 需要更高蛋白刺激 |

## 运动干预策略

### 力量训练（核心）

| 参数 | 建议 |
|------|------|
| 频率 | 2-3次/周 |
| 强度 | 60-80% 1RM |
| 动作 | 多关节、功能型（深蹲、硬拉、推、拉） |
| 渐进 | 缓慢渐进，关注动作质量 |

### 蛋白质补充

| 建议 | 说明 |
|------|------|
| 每日蛋白 | 1.2-1.6 g/kg/天（高于年轻人的1.6-2.2） |
| 每餐蛋白 | 25-40g含~2.5-3g亮氨酸 |
| 乳清蛋白 | 亮氨酸含量高，MPS激活迅速 |
| 训练后窗口 | 训练后0-2小时内补充 |

### 有氧训练

- 中等强度有氧 150-300分钟/周
- 维持心肺功能，减缓线粒体衰老
- 配合力量训练达最佳效果

## 合成代谢抵抗

**特点**：老年肌肉对同剂量蛋白质和训练刺激的MPS反应减弱。

**克服策略**：
- 每餐更高亮氨酸（~3g vs 年轻人2-2.5g）
- 规律运动（一次性运动后MPS敏感性暂时提升24-48h）
- 维生素D和Omega-3补充可能辅助

## 卧床/失用性萎缩

短期卧床（5-7天）可导致老年人下肢肌肉量下降1-2kg。

**预防**：
- 卧床期间低强度阻力训练（BFR训练有效）
- 尽早下床活动
- 蛋白质摄入不低于1.2 g/kg/天
