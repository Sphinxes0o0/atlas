# 运动与心理健康 (Exercise & Mental Health)

## 定义

规律运动是抑郁、焦虑等常见心理健康问题的有效非药物干预手段。运动通过神经化学、生理和心理社会多重机制影响心理健康。

## 运动对抑郁的疗效

**Meta分析证据** (2023, 多篇系统综述):

| 运动类型 | 效果量 (Cohen's d) | 建议 |
|---------|-------------------|------|
| 有氧运动 | 0.5-0.8 (中等-大效应) | 30-45分钟/次，3-5次/周 |
| 阻力训练 | 0.4-0.6 (中等效应) | 8-10个动作，2-3组 |
| HITT | 0.6-0.9 | 短时高效 |
| 瑜伽/冥想运动 | 0.5-0.7 | 身心整合 |

**关键发现**：有氧和阻力结合的并发训练效果最优。效果呈剂量依赖，但过度训练有害。

## 作用机制

### 神经生物学

| 机制 | 描述 |
|------|------|
| BDNF↑ | 脑源性神经营养因子促进神经元新生和突触可塑性（海马体） |
| HPA轴调节 | 改善下丘脑-垂体-肾上腺轴失调，降低皮质醇 |
| 单胺假说 | 增加5-羟色胺、多巴胺、去甲肾上腺素可用性 |
| 内啡肽释放 | 运动后"欣快感" |
| 抗炎效应 | 降低促炎因子（IL-6, TNF-α），改善神经炎症 |

### 心理社会

- 自我效能感提升
- 注意力从负面思绪转移
- 社会连接（团体运动）
- 成就感与掌控感

## 运动处方建议

| 参数 | 建议 |
|------|------|
| 频率 | 3-5次/周 |
| 强度 | 中等（60-75% HRmax），配合高强度间歇 |
| 时长 | 30-60分钟/次 |
| 类型 | 有氧为主 + 抗阻补充 |
| 持续性 | 至少8-12周效果稳定 |

## 注意事项

- 严重抑郁症患者：需在专业指导下开始运动
- 运动本身不是药物替代（但可辅助）
- 建立习惯最难，需社交支持和监督
- 运动成瘾也是可能的极端（需平衡）
