# Cognitive Performance & Exercise (运动与认知功能)

## Overview

Exercise is one of the most robust non-pharmacological interventions for enhancing cognitive function across the lifespan. Both acute bouts and chronic training yield measurable benefits via neurobiological pathways.

## Acute Exercise Effects

| Effect | Evidence |
|--------|---------|
| Working memory | ↑ immediately post-exercise |
| Executive control | Improved network efficiency |
| Memory consolidation | Enhanced encoding and consolidation |
| Post-exercise window | Improvements persist into recovery |

**Minimum dose**: Brief bouts (5 min) show benefits; optimal 20-30 min moderate-to-vigorous.

## BDNF: Central Mechanism

BDNF (Brain-Derived Neurotrophic Factor) is the primary mediator linking exercise to cognitive enhancement.

| Intervention | BDNF Effect |
|-------------|-----------|
| 6 min high-intensity cycling | 4-5× increase |
| 30 min moderate aerobic | Significant increase |
| Resistance training | Moderate increase |
| Combined exercise | Synergistic effect |

**Aging 2025 study**: Aerobic exercise restores hippocampal neurogenesis via Irisin/NLRP3 pathway (↓microglia inflammasome).

## Executive Function

| Domain | Exercise Benefit |
|--------|----------------|
| Inhibition | Improved |
| Working memory | Enhanced |
| Cognitive flexibility | Better task-switching |
| Planning | ↑ performance on Tower of London |

**Optimal training**: ≥12 weeks, ≥90 min/week aerobic exercise for adults 50+

**Intensity**: Moderate-to-vigorous intensity shows optimal executive function benefits.

## Hippocampal Volume

- Aerobic exercise increases hippocampal volume
- Particularly in older adults
- Linked to BDNF-mediated neurogenesis
- Associated with improved spatial memory

## Cognitive Benefits by Exercise Type

| Type | Cognitive Benefits |
|------|------------------|
| Aerobic | Processing speed, working memory |
| Resistance | Inhibitory control, cognitive flexibility |
| Combined | Global improvement |
| Dual-task | Task-switching, divided attention |
| Open-skill | Superior executive function vs closed-skill |
