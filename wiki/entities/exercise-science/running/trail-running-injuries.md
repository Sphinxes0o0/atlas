# 越野跑损伤与预防 (Trail Running Injuries & Prevention)

## 定义

越野跑因其多变地形、累积爬升和下坡离心负荷，具有与路跑不同的损伤谱。下肢损伤最为常见，损伤机制以过度使用为主，但急性损伤（扭伤、跌倒）比例高于路跑。

## 常见损伤类型

| 损伤 | 发生率 | 主要机制 |
|------|--------|---------|
| 踝关节扭伤 | 最高 | 不平地形、注意力下降 |
| 髂胫束综合征(ITBS) | 高 | 下坡离心负荷、臀中肌无力 |
| 足底筋膜炎 | 中-高 | 长时间站立/奔跑、越野鞋支撑不足 |
| 膝前痛(PFPS) | 中 | 上坡膝屈曲增大、下坡冲击 |
| 胫前痛/筋膜室综合征 | 中 | 坡度跑增加前侧肌群负荷 |
| 应力性骨折 | 低-中 | 训练量增加过快 |

## 越野跑特有的损伤风险因素

| 风险因素 | 影响机制 |
|---------|---------|
| 下坡跑 | 离心负荷增加3-5倍，肌肉微损伤累积 |
| 技术地形 | 足踝不稳定，急性扭伤风险 |
| 累积爬升 | 下肢后链过度负荷 |
| 长距离 | 疲劳导致技术变形，损伤风险指数上升 |
| 天气/地面 | 湿滑、泥泞增加跌倒风险 |

## 预防策略

### 力量训练

| 训练 | 目标 |
|------|------|
| 单腿深蹲 | 踝膝稳定 |
| 臀桥/侧卧抬腿 | 臀中肌力量（防ITBS） |
| 提踵训练 | 小腿/跟腱韧性 |
| 核心训练 | 躯干稳定性 |

### 技术优化

- 下坡：保持短步幅、前脚掌落地、手臂平衡
- 上坡：小步快跑、身体前倾
- 技术训练：日常加入越野跑专项技术练习

### 训练管理

- 渐进增加：每周里程增幅<10%
- 地形适应：先熟悉再加速
- 交叉训练：公路跑+力量+技术
- 恢复：高质量恢复周

## 急性损伤处理

| 损伤 | 立即处理 | 后续康复 |
|------|---------|---------|
| 踝扭伤 | RICE原则，制动 | 本体感觉训练，逐步负重 |
| 跌倒/擦伤 | 清洗消毒，伤口护理 | 观察感染 |
| 肌肉拉伤 | RICE，抗炎 | 渐进拉伸和力量恢复 |
