# Rehabilitation Exercise (康复运动)

## Definition

康复运动是针对运动损伤或手术后恢复设计的专项训练，旨在恢复功能、预防再伤、重返运动。

## Key Points

- **分期原则**: 急性期→亚急性期→功能训练期→重返运动期
- **渐进负荷**: 根据组织耐受度逐渐增加训练强度
- **功能整合**: 从单关节到多关节，从静态到动态
- **个体化**: 根据损伤类型、手术方式、个体反应调整

## Key Components

| 组成 | 内容 | 目标 |
|------|------|------|
| 关节活动度 | 被动/主动/抗阻 ROM | 恢复关节功能 |
| 力量训练 | 等长→等张→等速 | 渐进抗阻 |
| 本体感觉 | 平衡训练 | [[entities/exercise-science/physiology/proprioception]] |
| 神经肌肉控制 | 干扰训练 | 动作模式重建 |
| 功能训练 | 专项动作 | 重返运动 |

## Common Rehabilitation Protocols

### ACL 术后康复

1. 急性期：止痛、消肿、被动屈膝
2. 4-12 周：力量、本体感觉、步态
3. 3-6 月：进阶力量、跑跳训练
4. 6-12 月：专项训练、重返运动测试

### 肩袖损伤康复

- 优先激活冈下肌、小圆肌（外旋肌群）
- 肩胛稳定训练（middle trapezius, serratus anterior）
- 渐进抗阻外旋训练

## Return to Sport Criteria

| 指标 | 最低标准 |
|------|----------|
| 力量 | >90% 对侧 |
| 功能测试 | 单腿跳 >90% |
| Y-balance | >95% |
| 心理准备 | ACL-RSI >65 |
