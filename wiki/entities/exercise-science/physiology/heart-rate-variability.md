# Heart Rate Variability (心率变异性)

## Definition

心率变异性（HRV）是逐次心跳间期（R-R interval）的微小波动，反映自主神经系统（交感/副交感）功能状态。

## Key Points

- **生理基础**: 副交感神经（迷走神经）通过 acetylcholine 降低心率，HRV 高 = 恢复良好
- **测量指标**: RMSSD（最常用）、SDNN、LF/HF 比值
- **晨脉监测**: 连续测量 + 分析趋势，比单次绝对值更有意义
- **正常范围**: RMSSD 20-100ms 个体差异大，需建立个人基线

## HRV as Recovery Marker

HRV 是监测 [[entities/exercise-science/physiology/fatigue-recovery]] 状态的有效工具：

- **HRV 下降 >20%**: 可能存在过度训练或疾病
- **持续低迷**: 需要减量或休息
- **趋势分析**: 周平均 vs 个人基线比较

详见: [[entities/exercise-science/technology/hrv-monitoring]]

## Training Application

| HRV 状态 | 训练建议 |
|----------|----------|
| 高于基线 | 正常训练或适当加量 |
| 略低于基线 (<10%) | 维持或轻微减量 |
| 明显低于基线 (>20%) | 大幅减量或休息 |
| 持续低迷 | 主动恢复休息周 |

## Overtraining Detection

HRV 是早期发现 [[entities/exercise-science/physiology/overtraining-syndrome]] 的有效工具：

- 交感/副交感平衡失调是核心机制
- HRV 长期低迷 + 晨脉升高是典型信号
- ACWR 最佳范围 1.0-1.3
