# Overtraining Syndrome (过度训练综合征, OTS)

## Definition

过度训练综合征（OTS）是由于长期高强度训练与恢复失衡导致的复杂病理状态，表现为运动表现下降、持续性疲劳、神经内分泌失调和心理症状。

## Fatigue Spectrum

| 术语 | 可逆性 | 恢复时间 |
|-----|-------|---------|
| 急性疲劳 | 可逆 | 24-48h |
| 功能过度用力 | 可逆 | 1-2 周 |
| 非功能过度用力 | 较难逆 | 数周至数月 |
| OTS | 难逆 | 数月至 1 年+ |

## Core Mechanisms

### HPA Axis Dysfunction (下丘脑-垂体-肾上腺轴失调)

```
长期高强度训练 → 皮质醇持续升高 → 负反馈受损 → HPA 轴失调
```

### Autonomic Nervous System Imbalance

- **迷走神经张力下降** 是 OTS 早期指标
- 心率变异性（HRV）高频成分（HF）降低
- 交感神经相对增强

### Central Fatigue (中枢疲劳)

- 色氨酸/BCAA 比值升高 → 脑内血清素增加 → 疲劳感
- 多巴胺水平下降 → 动机下降

## Key Monitoring Indicators

| 指标 | 正常变化 | OTS 信号 |
|-----|---------|---------|
| 晨脉 | 稳定 | 升高 >5-10 次/分 |
| HRV | 高频稳定 | 总功率和 HF 下降 |
| 主观疲劳感 (RPE) | 与训练匹配 | 持续异常升高 |
| 训练表现 | 稳定或提升 | 持续下降 |

### ACWR (Acute:Chronic Workload Ratio)

```
ACWR = 近 1 周训练量 / 前 4 周平均训练量
```

| ACWR 范围 | 损伤风险 |
|----------|---------|
| 0.8-1.0 | 最低 |
| **1.0-1.3** | **最佳（甜蜜点）** |
| 1.3-1.5 | 中等增加 |
| >1.5 | 显著增加 |

## Prevention: 10% Rule

每周训练负荷增加不超过 **10%**，包括跑量、强度、时间等多维度。

## Recovery Strategies

| 严重程度 | 恢复方案 | 时间 |
|---------|---------|------|
| 轻度 | 训练量减少 40-60%，维持强度 | 2-4 周 |
| 重度 | 完全停止高强度训练，仅低强度活动 | 数月至 1 年 |
