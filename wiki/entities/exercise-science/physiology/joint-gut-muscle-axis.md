# Joint-Gut-Muscle Axis (关节肠道肌肉轴)

## Definition

运动训练引发的炎症通过关节-肠道-肌肉轴影响恢复效率。高强度训练同时影响关节软骨、肠道屏障和肌肉蛋白质代谢。

## Inflammatory Conduction Pathway

```
高强度训练
     ↓
组织微损伤 + 代谢压力
     ↓
炎症因子释放 (IL-6, TNF-α, CRP)
     ↓
     ├─→ 关节软骨炎症 → 疼痛/活动受限
     │
     ├─→ 肠道屏障受损（肠漏）→ LPS 进入血液
     │          ↓
     └─→ 系统性低度炎症
               ↓
          肌肉蛋白分解 ↑
          恢复速度 ↓
```

## Multi-Target Intervention Model

| 靶点 | 成分 | 推荐剂量 | 证据 |
|-----|-----|---------|-----|
| 关节软骨 | 氨基葡萄糖 | 1500 mg/天 | B 级 |
| 关节软骨 | 软骨素 | 800-1200 mg/天 | B 级 |
| 关节炎症 | MSM | 2-3 g/天 | B 级 |
| 肠道屏障 | 益生菌 | 10^9-10^10 CFU | B 级 |
| 肠道屏障 | 谷氨酰胺 | 5-10 g/天 | B 级 |
| 系统炎症 | Omega-3 | 2-3 g EPA+DHA | A 级 |
| 系统炎症 | 姜黄素 | 500-1000 mg | B 级 |

## Joint Support

### Glucosamine (氨基葡萄糖)

```
氨基葡萄糖 → 软骨基质合成（蛋白聚糖、糖胺聚糖）
    ↓
软骨细胞代谢支持
    ↓
软骨弹性与抗压性维持
```

### MSM (甲基磺酰基甲烷)

- 有机硫供体，支持胶原蛋白合成
- 抗氧化作用（ROS 清除）
- 炎症介质调节

## Gut Barrier Support

### Probiotics + Glutamine

```
谷氨酰胺 → 肠细胞主要能量来源 → 肠细胞增殖 → 紧密连接蛋白合成 → 肠道屏障完整 ↑
```

## Anti-Inflammatory Strategy

### Omega-3 Mechanism

```
Omega-3 (EPA/DHA) → 膜磷脂整合 → 促炎症介质转换
                                    ↓
                         Resolvin/Protectin/Maresin 合成
                                    ↓
                              炎症消退 (Resolution)
```

### Curcumin

- NF-κB 抑制 → 促炎基因表达 ↓
- 生物利用度增强：+ 胡椒碱 2000%↑

## Integrated Protocol

| 场景 | 方案 |
|-----|-----|
| 高强度训练期 | 氨基葡萄糖 + MSM + 益生菌 + 谷氨酰胺 + Omega-3 + 姜黄素 |
| 比赛后恢复 | Omega-3 3g + 姜黄素 1000mg + 谷氨酰胺 10g |
| 膝关节压力大 | 氨基葡萄糖 + 软骨素 + MSM + 胶原蛋白肽 |

## Safety Notes

| 成分 | 注意事项 |
|-----|---------|
| 氨基葡萄糖 | 虾蟹过敏者可能交叉反应 |
| 软骨素 | 抗凝治疗者注意 |
| 姜黄素 | 胆结石者慎用 |
