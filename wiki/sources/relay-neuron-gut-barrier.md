# Gut Barrier Function (肠道屏障功能)

## Overview

运动对肠道屏障功能有双向影响：中等运动改善屏障完整性，而高强度运动导致"肠漏"和内毒素转运。运动诱导的胃肠道综合征(EIGS)是运动员面临的关键问题。

## Key Findings

### 运动改善屏障功能

- 中等运动(40-70% VO2max)减少肠道通透性20-40%
- 训练增加紧密连接蛋白表达(claudin-1, occludin, ZO-1)
- 运动增加产丁酸菌(butyrate-producing bacteria)15-25%
- 运动诱导热休克蛋白HSP70上调50-200%
- 运动员肠道屏障参数优于久坐对照

### 肠道屏障损伤机制

- **腹腔低灌注**: 运动强度>70% VO2max时，腹腔血流减少50-80%
- **紧密连接破坏**: zonulin蛋白释放增加，肠道通透性升高
- **内毒素转运**: 脂多糖(LPS)进入体循环，触发促炎细胞因子风暴
- **I-FABP**: 肠细胞损伤特异性生物标志物，运动后升高

### 临床后果

- 马赛跑后LPS增加~284%，IL-6增加74倍
- 过度训练运动员: 慢性内毒素暴露，CRP持续升高
- 蛋白吸收损害: GI症状运动员氨基酸峰值浓度降低34%
- 恢复需要24-72小时

### 生物标志物

| 标志物 | 意义 |
|--------|------|
| I-FABP | 肠细胞损伤 |
| LBP | 内毒素暴露 |
| sCD14 | 免疫激活 |
| zonulin(粪便) | 紧密连接破坏 |
