# relay-neuron / biomechanics

## Core Content

跑步生物力学专项研究，涵盖步态分析、技术优化、损伤预防和装备技术。

### 主要研究主题

| 主题 | 关键内容 |
|------|---------|
| 步态分析技术 | VICON、IMU、压力平台等分析系统，跑步周期参数 |
| 步频与步幅优化 | 最佳步频170-185步/分，步幅与经济的权衡 |
| 跑步损伤生物力学 | 过度内旋、高冲击力与损伤的关系 |
| 下坡跑生物力学 | 离心负荷、制动控制、地形适应 |
| 跑鞋技术 | 缓冲材料（EVA/PEBA）、碳板科技、越野鞋设计 |
| 跑步经济性 | 生物力学因素对能量消耗的影响 |
