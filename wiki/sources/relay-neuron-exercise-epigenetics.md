# Exercise Epigenetics (运动表观遗传学)

## Overview

运动通过表观遗传机制调控基因表达，包括DNA甲基化、端粒长度维护和组织蛋白修饰。规律运动可延缓细胞衰老，影响代谢健康基因表达。

- `2026-05-11-task-4-1-exercise-epigenetics.md`

## Key Findings

### DNA甲基化

- 运动诱导位点特异性甲基化变化，与代谢功能改善和基因表达适应相关
- 运动后骨骼肌中观察到"表观遗传记忆"，再训练时适应加速
- 甲基化模式可作为运动响应性和代谢健康的生物标志物

### 端粒长度

- 力量训练与更长端粒相关，高强度力量训练(60+分钟/周)的个体端粒长约238个碱基对
- 相当于约3.9年的生物学衰老减少
- HIIT显示比有氧耐力训练更优的端粒效应

### 组织蛋白修饰

- 运动激活组蛋白乙酰转移酶(HATs)，促进运动响应基因的转录激活
- 组蛋白修饰与DNA甲基化协同调控长期基因表达变化

### 跨代效应

- 动物研究表明训练父母可将增强的代谢表型通过表观遗传机制传递给后代
- 人类证据有限
