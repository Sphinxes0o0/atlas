# relay-neuron / health-applications

## Core Content

运动作为医学干预手段的专项研究，涵盖心理、代谢、心血管和衰老等多个健康领域。

### 主要研究主题

| 主题 | 关键内容 |
|------|---------|
| 运动与心理健康 | 抑郁焦虑的运动干预，机制：BDNF↑、HPA轴调节、内啡肽 |
| 心血管健康与运动 | ACSM 2024指南，运动处方，剂量效应关系 |
| 糖尿病与运动 | 1型/2型糖尿病运动管理，GLUT4上调，胰岛素敏感性 |
| 衰老与肌少症 | 运动对抗年龄相关肌肉流失，合成代谢抵抗 |
| 肌肉萎缩与肌少症 | 卧床/失用性萎缩，蛋白质补充策略 |
| 睡眠质量与运动 | 运动改善睡眠的机制，时机建议 |
| 代谢综合征与运动 | 运动作为核心干预手段的效果量化 |
