# Exercise Immunology (运动免疫学)

## Overview

运动免疫学研究身体活动与免疫功能之间的复杂相互作用。中等运动增强免疫监视，而高强度训练可短暂抑制免疫功能("开放窗口"机制)。

## Source File

- `2026-05-11-task-3-1-exercise-immunology.md`

## Key Findings

### J型曲线

- 中等运动(30-60分钟/天)与上呼吸道感染(URTI)风险降低20-50%相关
- 马拉松/超马后URTI风险增加100-500%
- 单次运动>90分钟且在55-75% VO2max，诱导3-72小时的免疫抑制

### "开放窗口"理论

- 剧烈运动后免疫功能下降的时期，病原体可能趁机侵入
- 运动后24-72小时内淋巴细胞减少
- 机制: 儿茶酚胺↑、血流再分布、皮质醇释放

### 免疫指标

- **分泌型IgA(sIgA)**: 黏膜表面主要防御因子，精英运动员sIgA反应性变化
- **中性粒细胞/淋巴细胞比值(NLR)**: 新兴的运动员监测生物标志物
- **CALERIE试验**: 中等热量限制改善免疫代谢调节

### 实际应用

- 避免连续高强度训练>90分钟
- 高强度训练后允许24-48小时免疫恢复
- 使用HRV、主观疲劳量表监控训练负荷
- 睡眠优化(7-9小时)对免疫恢复至关重要
