# Source: Kinesiophobia — Injury Fear & Return to Sport Psychology

## Summary

运动损伤后心理障碍研究综合，涵盖kinesiophobia（运动恐惧症）的发生率、对再损伤风险的影响、以及CBT/分级暴露等干预方法。

## Key Topics

- Kinesiophobia prevalence (30-50% post-ACL)
- Fear-avoidance model in sports injury
- ACL-RSI psychological readiness scale
- Post-traumatic stress after sports injury (12.3% PTSD)
- Graded exposure therapy efficacy (SMD = -0.67)
- CBT for kinesiophobia (SMD = -0.82)
- Athletic identity and fear avoidance
- Interdisciplinary rehabilitation outcomes

## Key Findings

| Outcome | Finding |
|---------|---------|
| Kinesiophobia prevalence | 30-50% post-ACL reconstruction |
| ACL-RSI correlation | r = -0.42 to -0.59 with kinesiophobia |
| High kinesiophobia re-injury risk | HR = 2.47 |
| PTSD after serious injury | 12.3% (plus 28.6% subthreshold) |
| CBT effect size | SMD = -0.82 (large) |
| Number needed to treat | NNT = 2.4 |
